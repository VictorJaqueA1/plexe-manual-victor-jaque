# Manual de Plexe

Bienvenido al **manual completo de Plexe**, el framework de simulación para *platooning* vehicular y sistemas cooperativos de conducción autónoma.

---

## ¿Qué es Plexe?

Plexe es una extensión de **Veins** (que a su vez corre sobre **OMNeT++** y **SUMO**) diseñada específicamente para simular pelotones de vehículos autónomos conectados. Permite estudiar:

- Protocolos de comunicación V2V (Vehicle-to-Vehicle)
- Controladores longitudinales cooperativos (CACC, PLOEG, Consensus, ETC…)
- Escenarios de tráfico realistas con dinámica vehicular precisa
- Impacto de la red inalámbrica en la estabilidad del pelotón
